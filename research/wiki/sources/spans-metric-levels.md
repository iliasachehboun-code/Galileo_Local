# Niveaux lus par les métriques

Fiche : `research/raw/spans/04-metric-levels.md`. Page : https://docs.galileo.ai/concepts/metrics/custom-metrics/custom-metrics-ui-llm

Un `retriever` est une requête plus des documents. Un `llm` est l'historique vu par le modèle plus sa dernière sortie. Un `tool` est les arguments plus le résultat. `workflow` et `agent` exposent les enfants pour juger une trajectoire.
